# FreddyAI

Голосовой компаньон в образе Фредди для Android: чат с бесплатными нейросетями, живой голос Fish Audio,
пиксельная голова с эмоциями, распознавание речи, камера и управление глазами настоящей головы на ESP32.

Переписано с нуля на Kotlin + Jetpack Compose по исходникам FreddyAI 1.9.10 (MIT).

## Установка

Скачай `FreddyAI-x.y.z.apk` со страницы [Releases](../../releases/latest) и установи. Дальше приложение
само проверяет релизы на GitHub и предлагает обновиться (Ещё → О приложении → «Проверять обновления»).
Один раз Android попросит разрешить FreddyAI устанавливать приложения.

Android 8+, ARM.

## Возможности

- **Нейросети:** Groq, OpenRouter, Gemini, Mistral, Cerebras, Ollama и любой OpenAI-совместимый сервис.
  Ответ печатается и озвучивается по ходу. Если сервис упёрся в лимит — запрос уходит в следующий по списку.
- **Голос:** Fish Audio (`s2.1-pro-free` бесплатно), теги эмоций `[laughing]`, `[whispering]`, библиотека голосов,
  кэш фраз, громкость до 200%. Без ключа — системный голос.
- **Голова:** пиксельный Фредди из оригинала — эмоции, моргание, рот в такт речи, тык в нос. Можно загрузить свою.
- **Распознавание речи:** системное, Whisper (Groq) или Vosk офлайн, слово-активация «Фредди».
- **Режим разговора:** голова на весь экран, Фредди слушает после каждого ответа.
- **Зрение:** камера телефона или сетевая (ESP32-CAM), предметы и лица на телефоне, подробный разбор кадра по просьбе, журнал.
- **Плата:** ESP32/RP2040 по USB или Wi-Fi, режимы и яркость глаз, каталог из 419 плат, редактор кода,
  запись прошивки с телефона (ESP32-S2/S3/C3), готовые прошивки из оригинала.
- **Ещё:** быстрые фразы, музыкальная шкатулка, персонажи с памятью, поиск в интернете, Telegram-бот,
  перенос настроек файлом или QR-кодом с паролем, темы оформления.

## Сборка

Нужны JDK 17, Android SDK (platform 35, build-tools 35) и Gradle 8.9.

```bash
gradle :app:testDebugUnitTest
gradle :app:assembleRelease
```

Без ключа подписи релиз подписывается отладочным ключом. Ключ подписи хранится вне репозитория и подключается
файлом настроек: `-Pfreddy.signing=путь/keystore.properties` (поля `storeFile`, `storePassword`, `keyAlias`, `keyPassword`).
Обновления ставятся поверх только если подписаны тем же ключом.

Если путь к проекту длинный или с кириллицей, добавь `-Pfreddy.buildRoot=D:/build`.

## Выпуск новой версии

```bash
tools/release.sh 2.2.1 "Что нового"
```

Скрипт прогоняет тесты, собирает подписанный APK, коммитит, ставит тег и публикует релиз на GitHub.
Установленные приложения увидят его при следующей проверке.

## Где что лежит (`app/src/main/java/com/freddyai/app`)

| Файл | Что внутри |
|---|---|
| `App.kt` | Состояние, сохранение, шифрование (Keystore), формат резервной копии |
| `Net.kt` | Нейросети с цепочкой запасных, поиск в интернете, Fish Audio, погода, плата по UDP, Telegram-бот |
| `Brain.kt` | Разбор ответа (эмоция, теги), локальные команды, диалог |
| `Voice.kt` | Очередь озвучки с кэшем, громкость речи, распознавание, слово-активация |
| `Head.kt` | Пиксельная голова, нос, музыкальная шкатулка |
| `Vision.kt` | Камера телефона и сетевая, детекторы предметов и лиц |
| `Hardware.kt` | USB CDC, каталог плат, сборка и запись прошивки |
| `Updater.kt`, `UpdateUi.kt` | Обновление с GitHub |
| `Ui.kt` | Палитра, темы и общие элементы интерфейса |
| `MainActivity.kt`, `Screens.kt`, `More.kt`, `Extra.kt` | Экраны |

Загрузчик ESP32 (`com/freddyai/EspRomFlasher.java`, `FirmwarePackage.java`) и прошивки взяты из оригинала.
Помощник сборки прошивок для компьютера — `tools/firmware_compiler.py`.

## Тесты

`app/src/test` — разбор ответов, команды, резервная копия, цепочка нейросетей и Fish Audio на тестовом сервере,
запись готовых прошивок во все три чипа через имитацию загрузчика ESP32, сравнение версий обновлений.
